# Smart Clinic Management System - User Stories

## Admin User Stories
- **As an Admin**, I want to log in securely so that I can access administrative controls.
- **As an Admin**, I want to add new doctors with their specialty, availability, and contact details so that patients can search and book appointments with them.
- **As an Admin**, I want to manage system users and schedules so that daily clinic operations run smoothly.

## Doctor User Stories
- **As a Doctor**, I want to log in to my portal so that I can view my personalized schedule.
- **As a Doctor**, I want to view my daily patient appointment schedule so that I can prepare for upcoming consultations.
- **As a Doctor**, I want to access patient medical records so that patients have accurate medication prescriptions.
- **As a Doctor**, I want to create and issue digital prescriptions for patients during or after consultations.

## Patient User Stories
- **As a Patient**, I want to register and log in so that I can manage my appointments securely.
- **As a Patient**, I want to search and filter doctors by name, specialty, or availability time so that I can find a suitable doctor.
- **As a Patient**, I want to book an appointment with a chosen doctor so that I can receive timely medical consultation.
- **As a Patient**, I want to view my appointment history and prescribed medications so that I can track my treatment plan.
